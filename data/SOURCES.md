# Источники данных о прогрессе RIGGED

Файл `progress.json` собран из внутренних документов проекта, отчётов и ревью независимых критиков и истории коммитов. Здесь описано, что откуда взято и по каким правилам.

## Источники

1. **Технический roadmap** — вехи M0–M9, пакеты 0–23 (§8), решения владельца (§4.5), бэклог M4a. Номера пакетов в roadmap — основной ориентир.
2. **Отчёты и ревью** (`docs/build/`) — отчёты пакетов, ревью пакетов, проверки критиков по вехам, заметки о раннере и off-screen запуске. Номера в именах файлов (например, `PACKAGE_2_REPORT.md`) могут не совпадать с номерами пакетов roadmap: пакет «2» отчёта соответствует пакету 4 roadmap (по сообщению коммита `ee68ec4`).
3. **История коммитов** кода игры и документации — даты изменений, ссылки на коммиты, changelog.
4. **Решения владельца** — использованы только даты и заголовки. Содержание решений не публикуется.

## Правила статусов

- **completed** — есть независимое ревью или критик с вердиктом PASS (в том числе «PASS с исправлениями» или PASS после повторной проверки). Для каждого такого статуса указан файл ревью.
- **testing** — реализовано и закоммичено, но независимой проверки нет или повторная проверка не проведена.
- **in_progress** — работа идёт прямо сейчас (есть незакоммиченные изменения в рабочем дереве или отдельные артефакты).
- **planned** — не начато.
- PASS «с исправлениями» без повторной проверки исправлений даёт `testing`, а не `completed`.
- Если источники противоречат друг другу или повторной проверки после исправлений не найдено, задача или веха получает `"uncertain": true` с пояснением в `details` или `note`.

## Даты

- Дата вердикта — из текста ревью, если она там указана. Иначе — дата последнего коммита, который изменил файл ревью.
- Даты файлов без коммита (артефакты рабочего дерева) — дата файла.

## Проценты и счётчики

Процентов в данных нет. Счётчики — число задач по статусам, число вех, число тестов, числа из отчётов. Например, «17 задач completed» — это число задач в `tasks` со статусом `completed`.

## Тесты

Цифры берутся из последней проверки каждой вехи (раздел `tests` в `progress.json`). Окно и unit-наборы запускались off-screen. Падающие тесты перечислены в `known_issues`.

## Приватность

- Сюжетные детали не публикуются вообще: только нейтральные названия. Список запрещённых терминов проверяется при каждой сборке.
- Не публикуются: локальные пути, адреса почты, токены, личные данные владельца, идентификаторы лицензий, названия приватных репозиториев, внутренние имена документов, хэши коммитов, идентификаторы агентов.
- Ссылки в данных обобщены: «внутренний документ», «ревью критика», «коммит кода/документации», «артефакт проверки».

## Ограничения

- Видео M5 версии v3 и пакеты 18–19 не проверены критиком. Их статус отражает незавершённость.
- Пакеты 3a и 3b: ревью документации дало «нужны исправления», повторной проверки не найдено.
- Полный прогон паритета экономики (`final_model --compare`) в отчётах отмечен отдельно; в данных он не выделен как проверенный критиком.
- Запуск Windows-сборки на реальной машине не проверялся.
