# RIGGED · ход разработки — дизайн-система

Публичный сайт прогресса разработки RIGGED. Часть экосистемы ShozitDev: студийная рамка ультрамарином, контент на собственном поле игры. Файлы: `tokens.css`, `mockups/overview.html`, `mockups/tasks.html` (+ PNG 1440/390), `mockups/mockup.css`.

## 1. Концепция: «ведомость»
Сайт — не админ-панель, а **открытая ведомость** (ledger) игры: разлинованный журнал, где каждая задача — строка, каждая веха — засечка на одной линейке. Никаких сеток одинаковых карточек, плиток с тенями и «светофоров». Информация держится на линейках, типографике и выравнивании, как на shozit-site.

## 3. Сетка и раскладка (mobile-first)
- Контейнер `--container: 1312px`; поля 16 / 24 / 48px; колонки 4 / 8 / 12 при 0 / 600 / 1024px (как на shozit-site).
- Порядок страницы: шапка студии (логотип, «Rigged / Ход разработки», навигация студии) → разрез → **липкая линейка подразделов** (Обзор, Дорожная карта, Задачи, Тесты, Известные проблемы, Изменения; горизонтальный скролл на мобильном; активный — латунная подчёркивающая 2px) → hero со строкой статуса → блоки, разделённые одной линейкой 1px `--rg-rule`.
- Разделы «Готово / В работе / На тесте / В плане» — это **один список задач с фильтром**, а не четыре страницы (ссылки на них — `tasks.html?status=done` и т.п.); в навигации отдельно только «Известные проблемы» (они живут дольше задач).
- На ≥900px две колонки 5/7 для «Тесты / Изменения»; всё остальное одной колонкой ширины контейнера; текст ≤ 66ch.

## 5. Цвета и токены
См. `tokens.css`. Правила:
- **Латунь `--rg-accent` имеет одно значение: «сейчас»** — текущая веха, задачи в работе, активная вкладка, последняя обновлённая строка (2px снизу, аналог красной «latest»-линейки студии).
- **`--rg-issue #E0907A` — только проблемы и упавшие тесты.** Больше цветов нет.
- `--rg-raise #1A1E14` — фон раскрытой строки (полоса во всю ширину, не карточка).
- Контраст: текст 14.8:1, muted 7.7:1, accent 10:1, issue ≥6:1 на поле. `--rg-rule` — только декор.

## 6. Язык статусов (не светофор)
Статус = **форма знака + слово**; цвет вторичен и различает только «сейчас» и «проблема».
| Статус | Знак 10×10 | Цвет |
|---|---|---|
| Готово | закрашенный квадрат | текст |
| В работе | наполовину закрашен, сдвинут на 3px (разрез) | латунь |
| На тесте | рамка с точкой | текст |
| В плане | пунктирная рамка | muted |
| Проблема | рамка с диагональю | issue |
Знак всегда `aria-hidden`, слово всегда видно — статус читается в ч/б и при дальтонизме.

## 7. Ведомость задач и дорожная карта
**Строка ведомости** (`li.row > details > summary`): номер (T-58 / I-12) | название | статус | веха · область | дата обновления | шеврон. На мобильном мета-ряд уходит под название. Раскрытие — нативный `<details>`: описание, `dl` (веха, сборка, тесты, ссылки на коммит/изменения), спойлер-поля. Последняя обновлённая строка — латунная линейка 2px.
**Фильтр**: сегментированный `fieldset` радиокнопок со счётчиками (выбранный — инверсия текст/поле), поиск с нижней линейкой, переключатель «показывать спойлеры сразу». Состояние в `?status=&q=` (делится ссылкой), `role="status"` «Показано N из M».
**Дорожная карта без карточек**: одна линейка вех. ≥900px — горизонтальная: пройденный отрезок — сплошная линия текста 2px, текущий — латунная линия до процента готовности (`--p`), будущее — линейка `--rg-rule`; засечки-квадраты с той же грамматикой форм. <900px — та же линейка вертикально слева. Под засечкой: «M3 · сейчас», название Spectral, «58 %, 11 из 19». Текущая веха `aria-current="step"`.
**Тесты**: одна строка чисел + тонкая 8px полоса пропорций (пройдено / упало / пропущено, `role="img"` с текстом), дата и окружение прогона. **Изменения**: журнал «дата | версия + одна фраза».

## 8. Движение
Повтор «ledger being ruled» (`brand/motion/README.md`):
- Строки и вехи при появлении: линейка рисуется слева направо (`scaleX 0→1`, 450ms, `--ease-row`), затем содержимое поднимается (opacity 0→1, y 8→0, 420ms, шаг 60ms). Один раз.
- Дорожная карта: линия прогресса текущей вехи дорисовывается до `--p` одним жестом 700ms `--ease-cut`.
- Смена фильтра: без перетасовок; строки, оставшиеся видимыми, не двигаются, новые — короткое появление 240ms opacity. Никаких layout-анимаций.
- Раскрытие строки: шеврон 340ms; содержимое — opacity/translateY 8px.
- Раскрытие спойлера: `filter` не анимируется; размытый слой исчезает opacity 240ms, текст под ним уже чёткий.
- Только transform / opacity / clip-path. Без bounce, overshoot, loop. Переход между страницами можно взять из `motion.js` (две панели разреза). Можно без GSAP: CSS + IntersectionObserver достаточно.
- `prefers-reduced-motion: reduce` — всё мгновенно (токены длительностей обнуляются), ничего не скрывается.

## 9. Спойлеры
- В данных поле помечается `"spoiler": true` (задача целиком или отдельное поле/скриншот).
- Задача-спойлер: в строке вместо названия — «Спойлер: <нейтральная категория>», текст не грузится в DOM до раскрытия (JS подставляет из JSON по клику) — так он не утечёт в поиск, RSS и скринридер.
- Поле-спойлер внутри раскрытой строки: латунная левая линейка 2px, подпись «Спойлер: …» и кнопка «Показать» (`aria-expanded`, `aria-controls`). Размытие `blur(6px)` — только визуальная заглушка поверх нейтрального текста-заполнителя, `aria-hidden`, `user-select:none`.
- Глобальный переключатель «Показывать спойлеры сразу» (сохраняется в `localStorage`, по умолчанию выкл). Скриншоты — как на странице игры (`details.spoiler` с метой-разрезом).

## 10. Доступность
WCAG 2.2 AA: контраст выше; фокус — 2px латунная рамка с отступом 3px; skip-link; landmarks (`header`, `nav` ×2 с подписями, `main`, `footer`); `aria-current="page"` во вкладках; нативные `details/summary`, `fieldset/legend`, радиокнопки; цель касания ≥44px на мобильном; статус не только цветом; `lang="ru"`/`en`; даты в `<time datetime>`; страница полностью читаема без JS (статичная разметка из сборки, JS только улучшает фильтр).

## 11. Бюджет производительности
HTML ≤ 30 КБ gz, CSS ≤ 15 КБ, JS ≤ 10 КБ (без зависимостей), `progress.json` ≤ 60 КБ gz; шрифты — только нужные начертания с `unicode-range` (Spectral 400i/600/800 + Golos variable, ≈ 180 КБ, грузятся по требованию); изображений по умолчанию нет. LCP < 1.5 с на 4G, CLS < 0.05, без внешних CDN.

## 12. Архитектура (GitHub Pages)
```
rigged-progress/
  index.html  tasks.html  roadmap.html  tests.html  issues.html  changelog.html
  assets/css/{tokens.css, site.css}   assets/js/progress.js   assets/fonts/ (+ licenses/)
  data/progress.json     # единственный источник правды
  tools/build.mjs        # опц.: пререндер HTML из JSON (без зависимостей)
```
- Чистые HTML/CSS/vanilla JS, без фреймворков. `progress.js` делает `fetch(new URL('data/progress.json', document.baseURI))` — **все пути относительные**, сайт работает под базовым путём (`/rigged-progress/`) и локально. Без `/`-абсолютных ссылок; при необходимости `<base href>` подставляется при сборке.
- Предпочтительно пререндерить разметку из JSON скриптом в CI (GitHub Actions → Pages), JS только для фильтра/поиска/спойлеров: работает без JS и индексируется.
- Схема JSON (кратко): `{ updated, build, currentMilestone, milestones:[{id,title,date,state}], tasks:[{id,title,status:"done|progress|testing|planned",milestone,area,updated,body,spoiler,fields}], issues:[…], tests:{passed,failed,skipped,env,ran}, changelog:[{date,version,text}] }`.
- `404.html` в стиле сайта; RSS/Atom изменений генерируется той же сборкой.

## 13. Шрифты и лицензии
Spectral и Golos Text — SIL OFL 1.1. Скопировать woff2 из `shozit-site/site/assets/fonts/` в `rigged-progress/assets/fonts/` вместе с `licenses/Spectral-OFL-1.1.txt` и `licenses/GolosText-OFL-1.1.txt`; переиспользовать блок `@font-face` из `shozit-site/site/assets/css/base.css` (разбиение latin/cyrillic через `unicode-range`). OFL разрешает распространение с сайтом при сохранении лицензии; не переименовывать и не продавать шрифты отдельно. Макеты ссылаются на шрифты shozit-site по относительному пути только для предпросмотра.

## 14. Чего не делать
Карточки с тенями, сетки плиток, круговые диаграммы, градиенты, неон, скругления >2px, зелёный/жёлтый/красный «светофор», капс с трекингом, эмодзи-статусы, второй акцентный цвет, анимации на каждом ховере.
